Modes

Pick what each run does

Request

Each account joins the clan you set, sends your troop request and, if you tick Leave, leaves again. A request only counts when the game confirms it was sent.

Run account

Opens each account, clears the pop-ups, and reads its player tag from the profile. You get the list of tags to copy, plus the IDs it could not finish.

Name change

Renames accounts in bulk. It costs more coins than the other modes (see below).

What you get
  • Floating controlPause, resume or stop the run from a ball over the game.
  • Pop-ups handledGame windows the bot knows are cleared. A screen it does not know restarts the game once, then the run goes on with the next ID.
  • Fixes for everyoneWhen a new game screen is taught, the fix reaches every player's bot by itself.
  • Starts after a rebootWith the login remembered, the bot opens, checks for an update and starts again after a 60-second countdown.
Before you buy

What your device needs

  • A rooted, 64-bit Android device or emulator, Android 8 or newer (for example MuMu Player 12 or LDPlayer 9)
  • A 720 × 1280 screen at 320 dpi (the bot can set it)
  • Internet the whole time a run is going

Check your device and game version with the seller before you pay. Game updates can affect automation.

Coins

What a run costs

Coins are used only while a run is going, by the server's clock. Pausing, logging in and adding a new phone cost nothing.
