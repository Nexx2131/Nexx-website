When do coins go down?

Only while a run is going. Time is reserved a little ahead; a normal Stop gives the unused part back.

What happens at 0 coins?

You can still log in. A run waits for coins and goes on by itself when coins are added.

If the app crashes or the internet drops?

At most the last 45 seconds that were reserved can be used up. Internet is needed the whole time a run goes.

Are coins money?

No. NEXX coins are prepaid bot running time, not a currency or an investment.
