Install NEXX Bot

Get the APK onto your rooted device or emulator.

Steps
  1. Open the Downloads page on the device and tap Download.
  2. Allow that source to install apps when Android asks.
  3. Open the APK and install it.
  4. Updating later? Install over the old copy. Do not uninstall first: your settings and login stay.

Both apps

Log in and redeem a code

The same NEXX account works in both apps.

Steps
  1. Open the app. It starts on the login page; nothing works without a login.
  2. Log in with your NEXX account ID and password. Pick Remember login: Forever for a device that must restart on its own.
  3. Got a code? Choose Redeem code, type your account ID and the code. Each code works once.

NEXX Bot

Permissions and screen

One-time setup per device.

Steps
  1. Log in first (the guide before this one).
  2. Home → open the Permissions row → Enable all.
  3. Allow the superuser prompt and tick "Remember choice forever". The bot switches on overlay, accessibility, notifications and battery by itself.
  4. The screen must be 720 × 1280 at 320 dpi; the bot sets it with root.

NEXX Bot

The Request account

Join your clan, send the troop request, leave.

Steps
  1. Open Special and choose Request.
  2. Type the name of your account folder, then Scan and load accounts. Start with one or a few.
  3. Set the clan tag and the request text. Tick Leave if each account should leave the clan after its request.
  4. Press Continue, then Start. Use the floating ball to pause, resume or stop.
  5. A request counts only when the game confirms it was sent. 1 coin per 24 h on one device.

NEXX Bot

The Run sequence

Open each account and collect its player tag.

Steps
  1. Open Special and choose Run account.
  2. Type the name of your account folder, then Scan and load accounts.
  3. Press Continue, then Start. The bot opens each account, clears the pop-ups and reads its player tag from the profile.
  4. At the end, copy the list of tags. The IDs it could not finish are listed too.
  5. 1 coin per 24 h on one device.

NEXX Farm

Install NEXX Farm

No root needed.

Steps
  1. Open the Downloads page on the phone and tap Download.
  2. Allow that source to install apps, then install the APK.
  3. Android 13 and newer: App info → ⋮ → Allow restricted settings, or Android keeps Accessibility greyed out.
  4. Turn on NEXX Farm's accessibility service, and allow screen recording when asked.

NEXX Farm

Farm and donate setup

Army link, battle end and clan.

Steps
  1. Log in to Clash of Clans on the phone first (an English account).
  2. Paste your copy-army link. The bot saves and uses it each run.
  3. Set End battle at (10–100 %, default 50) and the number of attacks.
  4. Choose donating: private clan or request clan. Optionally "until the loot runs out".
  5. Leave Running hours off to run until Stop, or turn it on for 1–24 hours. Press Start.

How coins are used

What a day of running costs.

Read
  1. NEXX Bot: 1 coin = 24 h on one device (Name change: 100).
  2. NEXX Farm: 2 coins = 24 h farming, 4 with donating. Wall upgrades add 5 (7, or 9 with donating).
  3. Coins go down only while a run is going. Pauses are free.
  4. At 0 coins a run waits, and goes on when coins are added.
